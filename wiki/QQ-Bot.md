# QQ 官方机器人

## 接入

1. 在 [QQ 开放平台](https://q.qq.com/) 创建机器人。
2. 将 AppID 和 AppSecret 填入设置页并启用 QQ 官方机器人。
3. 把机器人添加到目标群。群内点歌或使用指令时需要先 `@机器人`，私聊不需要。
4. 如需限制群，在 `allowedGroupOpenids` 中填写允许使用的群 OpenID；留空表示不额外限制。

未认证机器人通常仅管理员可以使用，且只能添加到管理员担任群主的群。个人或企业认证后，可按 QQ 开放平台规则配置更广的服务范围。

## 指令

- `/list`：列出当前点歌队列，最多显示前 8 首，并显示难度、星数与时长。
- `/np`：显示“主播正在听”的 Artist/Title 和 osu! 链接，不显示客户端状态或难度名；需要启用 tosu。
- `/skip [序号]`：省略序号等同 `/skip 1`。点歌者只能跳过自己的项目，主播可以跳过任意项目。
- `/help`：显示点歌方法与指令帮助。
- `/ownerid`：返回当前用户对该机器人的 OpenID，用于配置主播权限。

在 QQ 开放平台的“指令配置”中添加 `list`、`np`、`skip` 和 `help`，用户输入 `/` 时即可看到原生菜单。

## 配置主播权限

1. 在需要管理点歌的群内发送 `@机器人 /ownerid`。
2. 复制机器人回复的 OpenID，填入设置页“主播 OpenID”。
3. 如果还要通过私聊管理，再私聊发送 `/ownerid`，将返回值另起一行填入。

群聊与私聊可能使用不同 OpenID。OpenID 不是 QQ 号，只对当前机器人有效。

## 昵称、头像与隐私

QQ 群消息不一定提供完整昵称和头像。程序会优先读取可用昵称；没有昵称时显示“群友”，不会在 Web 或 Overlay 中展示 QQ 号或 OpenID。

QQ 点歌在 Overlay 中优先使用对应 beatmapset 的 osu! 封面作为头像：

```text
https://assets.ppy.sh/beatmaps/{beatmapset ID}/covers/list.jpg
```

谱面尚未解析或没有封面时显示默认头像。

## 回复行为

IRC 开启时，谱面成功发送后机器人会回复“点歌推送成功”；IRC 关闭时回复“点歌已加入队列”。限流、队列已满、谱面不存在和处理失败也会回复对应结果。
